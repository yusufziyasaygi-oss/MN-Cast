# MN Cast CI build package

This repository builds two installable debug APKs with GitHub Actions:

- `MN-Cast-TV.apk` — Android TV / Google TV receiver with AirPlay plus MN Cast Android mirroring receiver.
- `MN-Cast-Sender.apk` — Android phone sender for full-screen mirroring to MN Cast TV.

Run **Actions → Build MN Cast APKs → Run workflow**. Download the generated artifacts after both jobs finish.

TV code is derived from GPLv3 Shield AirPlay / android-airplay-server. Corresponding source and license obligations apply.
